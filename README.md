# CNN Lab Student Submission Repository

Welcome! This repository is open for all students to upload their CNN lab work.

## What to upload
Each student must upload **2 files**:

1. **Jupyter Notebook file** (`.ipynb`)
2. **Observation file** (`.md`, `.pdf`, or `.docx`)

## File naming format (required)
Use this exact pattern for both files:

`student-name_roll-number.extension`

### Examples
- `ananya-sharma_23cs101.ipynb`
- `ananya-sharma_23cs101.md`

## Required content in your files

### 1) Jupyter Notebook (`.ipynb`)
Include:
- Title of experiment/lab
- Objective
- Dataset details
- Model steps and code
- Output graphs/metrics
- Short conclusion

Notebook metadata (top markdown cell) should contain:
- Student Name
- Roll Number
- Course/Subject
- Lab/Experiment Number
- Submission Date

### 2) Observation file (`.md`, `.pdf`, or `.docx`)
Include:
- Student Name
- Roll Number
- Lesson/Topic name
- Key observations
- Challenges faced
- What you learned
- Final conclusion

## Direct upload setup (GitHub web)
1. Open this repository.
2. Click **Add file** → **Upload files**.
3. Drag and drop your two files.
4. Check file names follow the required format.
5. Add a commit message, for example: `Submit CNN Lab - 23CS101`.
6. Click **Commit changes**.

## Quick checklist before upload
- [ ] I uploaded both required files
- [ ] File names follow `student-name_roll-number.extension`
- [ ] Notebook includes objective, code, output, and conclusion
- [ ] Observation includes lesson, observations, and learning
- [ ] My name and roll number are present in both files

---
If you are uploading again, keep the same naming style and update only your latest correct files.
